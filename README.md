# Money Tracking Test

## About

This project is for testing web app 'Money Tracking' using Playwright (Typescript) supports multiple test environment.

## How to run this test

Install pakage by run command `bun install`

1. Test without ui

> `TEST_ENV=local bunx playwright test`

2. Test with ui

> `TEST_ENV=local bunx playwright test --ui`

By TEST_ENV can be local, dev, staging, production
